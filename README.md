# Selva Institute landing page

Landing page institucional estática, preparada para publicação no GitHub Pages.

## Pré-visualização local

Abra `index.html` no navegador ou execute um servidor HTTP simples na raiz do projeto.

## Estrutura

- `index.html` — conteúdo e estrutura da página
- `styles.css` — sistema visual e responsividade
- `script.js` — menu, acordeão e animações sutis
- `assets/` — arquivos da marca
